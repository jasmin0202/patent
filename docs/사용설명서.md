# 발명 조사 시스템 사용설명서

대표님용. 이 폴더(`D:\patent`)를 Claude Code로 열고 한 줄 질문을 던지면, 담당 에이전트 7개가 조사해서 출처가 붙은 보고서를 만들어 줍니다. 이 문서는 "무엇을 치면 무엇이 나오고, 막히면 어떻게 하는지"만 적었습니다. 설계 설명은 `README.md`, 규칙은 `CLAUDE.md`에 있습니다.

---

## 1. 이 앱이 하는 일

"욕실용품 하나 기획해봐" 같은 넓은 질문이나 "휴대폰 뒷면 스크롤 패드" 같은 구체적 아이디어를 받아서,

1. 사람들이 실제로 무엇을 불편해하는지 모으고,
2. 이미 있는 제품과 특허를 찾아 빈 자리를 가리고,
3. 왜 지금인지, 어떤 모양으로, 얼마에 만들 수 있는지를 적고,
4. 그 주장들을 다른 담당이 출처를 다시 열어 검증한 뒤,
5. 신호등·가정표·근거 목록이 붙은 최종 보고서를 씁니다.

모든 숫자와 주장에는 출처와 등급(확인됨 / 추정 / 미확인)이 붙고, 못 찾은 것은 못 찾았다고 씁니다.

---

## 2. 시작 전 준비

| 준비물 | 필수 여부 | 없으면 |
|---|---|---|
| Claude Code (데스크톱 앱 또는 터미널)로 `D:\patent` 열기 | 필수 | 아무것도 안 됨 |
| KIPRIS API 키 (환경변수 `KIPRIS_API_KEY`) | 선택 | 한국 특허를 Google Patents로만 찾고 보고서에 "KIPRIS MCP 미설정"이라고 적힘 |
| Aside 브라우저 앱 **실행 상태** + 쿠팡·알리바바 로그인 + 크레딧 잔액 | 선택 | 쿠팡·아마존·알리바바 리뷰·단가 조사를 건너뛰고 보고서에 "Aside 미실행"으로 적힘 |

Aside를 쓰실 거면 조사를 시작하기 **전에** 세 가지를 확인해 주세요.
- Aside 앱이 켜져 있는가 (꺼져 있으면 "Aside isn't running" 오류)
- Aside 브라우저 안에서 alibaba.com에 로그인하고 캡차를 한 번 통과해 두었는가
- 크레딧이 남아 있는가 (바닥나면 "402 Insufficient credits"로 전부 실패)

설치 방법은 `README.md`의 "설치" 절에 있습니다.

## 3. 조사 시작하기

Claude Code 입력창에 이렇게 칩니다.

```
/invent 욕실용품에서 가장 필요한 발명품을 고안해줘
```

구체적인 아이디어가 있으면 그대로 씁니다. 그러면 탐색 단계를 건너뛰고 바로 심층 조사로 갑니다.

```
/invent 휴대폰 뒷면에 붙이는 스크롤 패드
```

그 다음은 가만히 두시면 됩니다. 총괄이 영역을 쪼개고 담당을 띄우고 결과를 파일로 저장합니다.

---

## 4. 진행 중 대표님이 하실 일은 두 번뿐

| 시점 | 총괄이 묻는 것 | 대표님 답 예 |
|---|---|---|
| 탐색이 끝났을 때 | 후보 3개와 점수표를 보여주고 "하나를 고르시거나 '전부'" | `2번`, `전부`, `A랑 C` |
| 심층 조사가 끝났을 때 | 최종 보고서 경로와 한 줄 결론·가장 큰 위험·사람이 확인할 것 3개 | 읽고 다음 지시 |

그 외에는 혼자 진행합니다. 중간에 로그인 화면·캡차·접근 차단을 만나면 우회하지 않고 멈춰서 "막힌 출처"에 적어 두고, 전달 시점에 한 번에 알려 드립니다.

소요 시간 감: 넓은 질문은 탐색 20~30분, 후보 하나당 심층 30~60분. 후보 3개를 전부 하면 두세 시간입니다.

## 5. 결과 읽는 법

결과는 `runs/<날짜>-<주제>/` 폴더에 쌓입니다. 파일 앞 숫자가 단계입니다.

```
runs/2026-10-23-bathroom/
  00-질문.md            질문 해석, 어느 단계부터 시작했는지, 상한, 재개·실패 기록
  01-영역.md            영역 쪼갠 이유
  01-불편-<영역>.md     영역별 불편 목록 (인용·출처·근거 개수)
  02-점수표.md          불편 순위표 → 상위 3개 후보
  29-출처확인.md        1단계 URL 기계 확인
  50-종합요약.md        후보 3개 결론 한눈에  ← 먼저 여기부터
  A-<후보>/
    10-기존해법.md      이미 있는 제품·특허와 빈 자리
    11-왜지금.md        무엇이 달라졌는가
    12-보조-<출처>.md   한 출처 한 질문 깊이 판 것 (KIPRIS, 킥스타터, 쿠팡 등)
    20-디자인.md        핵심 기능 3개, 치수, 스케치 지시문(한/영)
    21-구현원가.md      부품 단가, 인증, 막힐 지점, 시제품 경로
    22-단면도.svg       단면 개념도 (브라우저로 열림)
    29-출처확인.md      이 후보의 URL·특허번호·인용문 기계 확인
    30-검증.md          주장별 판정, 등급 조정, 담당 간 모순
    40-최종보고서.md    ← 결론은 여기
```

**40-최종보고서를 읽는 순서**
1. 한 줄 결론 — 누구의 어떤 불편을 무엇으로, 왜 지금, 결론(진행 / 조건부 진행 / 지금은 아님)
2. 신호등 5개 — 특허 여지, 시장 틈, 왜 지금, 원가·가격, 디자인 차별. 빨강이 하나라도 있으면 그 이유부터
3. 7절 가장 큰 위험 하나
4. 6절 가정표 — 우선순위 1~3번에 "가장 싸고 빠른 확인 방법"과 "무엇이 나오면 접는가"가 적혀 있습니다. 다음 행동은 여기서 고르시면 됩니다.
5. 8절 못 한 조사 — 막힌 출처, 상한에 걸린 것, 사람이 직접 확인할 것

**등급 뜻**
- 확인됨: 서로 독립된 출처 3개 이상이 같은 말을 함
- 추정: 출처 1~2개, 또는 범위가 다름 (한 사람 말을 전체로 넓힘)
- 미확인: 출처 없음, 담당의 판단. 보고서에서 숫자로 쓰지 않음

등급은 검증 담당이 내릴 수만 있고 올릴 수는 없습니다. 담당이 "확인됨"이라고 써도 검증에서 3개를 못 세면 "추정"이 됩니다.

## 6. 그림이 필요할 때

- `22-단면도.svg`: 총괄이 치수대로 그린 구조 설명용 개념도입니다. 사진 같은 렌더는 아닙니다.
- 사진 같은 이미지가 필요하면 `20-디자인.md`의 "스케치 지시문"(한국어·영어 한 벌씩)을 복사해 이미지 생성 도구(Midjourney, DALL·E 등)나 디자이너에게 그대로 주시면 됩니다. 이 앱에는 이미지 생성 도구가 연결돼 있지 않습니다.

## 7. 결과를 기계로 한 번 더 검사하기

보고서를 받기 전에 두 명령을 돌리면 빠진 파일·상한 초과·등급 누락·죽은 링크를 잡습니다. 터미널에서 프로젝트 폴더 기준으로 칩니다.

규칙 검사 (산출물 유무, 조사 횟수 상한, 보고서 등급·가정표·신호등):

```bash
python -I tools/완료확인.py runs/2026-10-23-bathroom
```

출처 검사 (URL 열림 여부, 특허번호↔링크, 인용문↔본문. 하위 후보 폴더까지 전부):

```bash
python -I tools/출처확인.py runs/2026-10-23-bathroom --out runs/2026-10-23-bathroom/29-출처확인.md
```

"위반 N건"이나 "링크 없음 → 삭제 대상"이 나오면 그 줄을 총괄에게 알려 주시면 고칩니다.

## 8. 막혔을 때

| 증상 | 뜻 | 하실 일 |
|---|---|---|
| "Aside isn't running on this machine" | Aside 앱이 꺼져 있음 | Aside 앱을 켜고 "다시 돌려 줘" |
| "402 Insufficient credits" | Aside 크레딧 소진 | 충전 후 "다시 돌려 줘". 한 번에 하나씩 순차 실행됨 |
| 알리바바 "로그인 예외"·"비정상 트래픽" 캡차 | 봇 판정 | Aside 브라우저에서 alibaba.com 로그인·캡차 통과 후 재시도 |
| 유튜브 "Quota exceeded" | 유튜브 API 일일 할당량 초과 | 다음 날 재시도, 또는 그대로 두면 보고서에 "0건"으로 적힘 |
| "KIPRIS MCP 미설정" | API 키 없음 | README대로 키 발급·등록 후 Claude Code 재시작 |
| KR 특허 "청구항 미확인" | KIPRIS 도구가 청구항 본문을 안 줌 | 보고서의 "사람이 확인할 것"에 적힌 번호를 KIPRIS나 변리사에게 |
| 조사 도중 "세션 한도" 오류로 멈춤 | 사용량 한도 | 한도가 풀린 뒤 Claude Code를 다시 열고 "다시 열었어"라고 치면 저장된 파일을 보고 이어서 진행 |
| 쿠팡에서 "리뷰 많은 순"이 없다고 멈춤 | 쿠팡 정렬 메뉴 차이 | 총괄이 "랭킹순 상위 10개 중 리뷰 최다"로 바꿔 다시 띄움 |

로그인·결제·글쓰기·좋아요·문의는 어떤 사이트에서도 하지 않습니다. 그런 화면이 나오면 멈추고 대표님께 넘깁니다.

## 9. 알아 두실 규칙 (요약)

- 조사 횟수 상한: 탐색은 영역당 웹검색 10회. 심층은 후보당 담당별 웹검색 20회, 보조 조사 4회, Aside 작업 6회. 상한에 닿으면 멈추고 보고합니다. 대표님이 넘기라고 하시면 넘기되 `00-질문.md`에 기록하고 규칙 검사기가 "초과"로 표시합니다.
- 특허번호는 실제 검색 결과에서 번호와 링크가 함께 나온 것만 씁니다. 번호만 적힌 특허는 출처 검사가 "삭제 대상"으로 잡습니다.
- 가격·별점·통계에는 조회일이 붙습니다. 시간이 지나면 다시 조회해야 합니다.
- 특허 겹침 판단은 전부 "문언 수준, 법적 판단 아님"입니다. 실제 판단은 변리사에게.
