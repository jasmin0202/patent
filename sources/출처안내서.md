# 출처 안내서

담당 에이전트가 "어디서 찾을지"를 고를 때 보는 문서. 사이트를 추가하려면 여기에 한 줄만 더한다.

## 접근 방법 표기

| 표기 | 뜻 | 누가 쓰나 |
|---|---|---|
| 검색 | WebSearch로 찾고 WebFetch로 페이지를 연다. `site:도메인` 검색어가 잘 먹힌다 | 모든 담당 |
| MCP | 이 프로젝트에 이미 연결된 정식 도구 | 모든 담당 |
| Aside | 로그인·봇 차단 사이트를 Aside 브라우저 작업으로 통째 넘긴다. **기본 사용 안 함.** `00-질문.md`에 "Aside 사용"이 있는 실행에서만, 2단계에서만, **읽기만** | solution-scout, build-cost, source-digger |
| 사람 | 자동으로 안 됨. 최종 보고서의 "사람이 직접 확인할 것"에 올린다 | 총괄 |

Aside 표시 사이트는 기본 실행에서 검색 스니펫과 열리는 대체 출처(네이버쇼핑·다나와·알리익스프레스·Kicktraq·앱 리뷰)로 대신하고 "원문 미열람"을 적는다. "Aside 사용" 실행에서의 작업 문장 예: "쿠팡에서 <검색어>로 검색해 랭킹순 상위 중 리뷰 많은 20개 제품의 이름·가격·별점·1~2점 리뷰 핵심 불만을 표로 정리. 읽기만 하고 아무것도 누르지 말 것." 로그인·캡차·402·미실행이면 재시도 없이 "Aside 막힘"으로 보고한다.

## 출처 확인 도구 (검증 담당)

`tools/출처확인.py`는 결과 파일의 URL을 전부 실제로 열어 열림/닫힘/차단 의심/중복을 표시하고, 특허번호↔링크, 인용문↔본문을 기계적으로 대조한다. 검증 담당이 2단계 끝에 돌린다. 담당들은 이 도구가 뒤에서 돈다는 걸 알고 쓴다: 링크 없는 특허번호, 요약을 인용으로 적은 것, 같은 글을 두 URL로 센 것은 걸린다.

## 출처를 더할 때
- 어느 질문에 쓰는지, 접근 방법, 검색 요령, 상한을 한 줄로 쓴다.
- 로그인이 필요하면 Aside로 표시한다. 기본 실행에서는 건너뛰므로, 열리는 대체 출처를 같은 줄에 적어 둔다.
