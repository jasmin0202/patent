# 점수표

총괄이 후보를 줄 세울 때 쓰는 기준. "가장 필요한 발명품"의 "가장"을 숫자로 정의한다.

## 근거 등급 (모든 숫자와 주장에 붙인다)

| 등급 | 기준 |
|---|---|
| 확인됨 | 서로 독립된 출처 3개 이상이 같은 내용을 말함. 같은 글의 댓글, 같은 기사를 베낀 다른 기사는 1개로 센다 |
| 추정 | 출처 1~2개, 또는 출처는 있으나 범위가 다름 (한 사람의 말을 전체로 넓힘) |
| 미확인 | 출처 없음. 담당의 판단 |

등급은 검증 담당이 내릴 수 있고, 올릴 수는 없다.

## 1단계 점수 (불편 → 후보 고르기)

불편 하나마다 네 항목을 1~5로 매긴다.

### 빈도 (얼마나 많은 사람이 말하나)
| 점 | 기준 |
|---|---|
| 5 | 독립 출처 10개 이상, 또는 통계로 대상 인구가 수백만 |
| 4 | 독립 출처 6~9개 |
| 3 | 독립 출처 3~5개 |
| 2 | 독립 출처 1~2개 |
| 1 | 담당 추측 |

### 강도 (얼마나 아픈가)
| 점 | 기준 |
|---|---|
| 5 | 돈을 써서 해결하려 했거나, 직접 만들었거나, 다쳤다 |
| 4 | 제품을 샀는데 실망해서 환불·재구매했다 |
| 3 | 임시방편을 쓰고 있다 (테이프, 고무줄, 다른 용도 물건) |
| 2 | 반복해서 투덜대지만 아무것도 안 한다 |
| 1 | 한 번 언급 |

### 기존 해법 부족 (지금 파는 걸로 안 풀리나)
| 점 | 기준 |
|---|---|
| 5 | 파는 제품이 없거나, 있어도 1~2점 리뷰가 그 불편을 그대로 반복 |
| 4 | 제품이 있지만 비싸거나(5만 원 이상) 설치가 어려워 안 쓴다 |
| 3 | 제품이 있고 절반쯤 푼다 |
| 2 | 괜찮은 제품이 있는데 사람들이 모른다 (마케팅 문제, 발명 문제 아님) |
| 1 | 잘 팔리는 좋은 제품이 이미 있다 |

### 제작 가능성 (우리가 소형 제품으로 만들 수 있나)
| 점 | 기준 |
|---|---|
| 5 | 기성 부품 조립, 전기 없음, 인증 간단, 원가 1만 원 이하 추정 |
| 4 | 사출 금형 1벌, 또는 간단한 전자 부품 |
| 3 | 전자+앱, 또는 방수·식품 접촉 인증 필요 |
| 2 | 새 기술이나 센서가 필요, 또는 의료기기급 인증 |
| 1 | 소형 제품으로는 안 됨 (설비, 건축, 서비스) |

### 계산

```
점수 = 빈도 × 1.0 + 강도 × 1.5 + 기존해법부족 × 1.5 + 제작가능성 × 1.0
최고 25점
```

강도와 기존 해법 부족에 가중치를 더 둔 이유: 많이 말하지만 안 아픈 불편(빈도 높고 강도 낮음)과, 좋은 제품이 이미 있는 불편은 발명 대상이 아니기 때문.

### 동점·탈락 규칙
- 같은 점수면 근거 등급이 높은 쪽이 위. 그래도 같으면 강도가 높은 쪽.
- 기존 해법 부족이 1~2점이면 총점과 무관하게 상위 3개에서 뺀다. 발명이 아니라 유통 문제.
- 제작 가능성이 1점이면 뺀다.
- 미확인 등급인 항목이 두 개 이상이면 "근거 부족"으로 따로 표시하고, 대표님께 "더 조사하면 올라올 수 있는 후보"로 보여준다.

### 1단계 순위표 양식

```
| 순위 | 불편 (영역) | 누가 | 빈도 | 강도 | 해법부족 | 제작 | 점수 | 등급 | 한 줄 이유 |
|---|---|---|---|---|---|---|---|---|---|
```

## 2단계 판단 (후보 하나의 최종 평가)

심층 결과가 모이면 다섯 항목을 다시 본다. 점수가 아니라 신호등(초록/노랑/빨강)으로 표시하고 이유를 한 줄 쓴다.

| 항목 | 초록 | 노랑 | 빨강 | 근거 파일 |
|---|---|---|---|---|
| 특허 여지 | 겹치는 특허 없음 또는 소멸 | 청구항이 좁은 특허 몇 건 | 핵심 기능을 그대로 덮는 등록 특허 | 10-기존해법 |
| 시장 틈 | 제품 없거나 전부 리뷰 나쁨 | 제품 있고 절반쯤 품 | 좋은 제품이 잘 팔림 | 10-기존해법 |
| 왜 지금 | 숫자로 뒷받침되는 변화 있음 | 변화는 있으나 추정 | 달라진 게 없음 | 11-왜지금 |
| 원가·가격 | 원가×3 이 경쟁가 이하 | 비슷 | 원가×3 이 경쟁가 초과 | 21-구현원가 |
| 디자인 차별 | 기존과 다른 점이 기능 3개 중 2개 이상 | 1개 | 겉모양만 다름 | 20-디자인 |

빨강이 둘 이상이면 최종 보고서 결론을 "지금은 아님"으로 쓴다. 그래도 보고서는 끝까지 쓴다. 왜 아닌지가 다음 후보에 쓸모 있다.

## 상한 (CLAUDE.md와 같음)
- 1단계: 영역당 웹검색 10회, Aside 0회
- 2단계: 후보당 담당별 웹검색 20회, 보조 4회, Aside 6회
- 검증: 주장 40개
